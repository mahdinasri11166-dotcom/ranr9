# بهینه‌سازی عملکرد مدل

**تیم توسعهٔ نو**

## پارامترهای مهم
| پارامتر | اثر |
|---------|-----|
| **n_threads** | تعداد هسته CPU (پیش‌فرض: هسته‌ها − ۱) |
| **n_batch** | سرعت خواندن پرامپت (۲۵۶–۱۰۲۴) |
| **n_ctx** | طول زمینه؛ بزرگ‌تر = RAM بیشتر، کندتر |
| **n_gpu_layers** | ۰=CPU ؛ بیشتر = GPU |
| **mmap** | لود سریع‌تر، RAM کمتر |

## پریست‌ها (load_advisor)
- **fast** — ctx کوچک‌تر، batch بالاتر
- **balanced** — پیش‌فرض
- **quality** — ctx بزرگ‌تر در صورت RAM کافی

## اگر کند است
1. GPU layers را افزایش دهید (اگر CUDA دارید)
2. ctx را از ۸۱۹۲ به ۲۰۴۸–۴۰۹۶ کم کنید
3. max_tokens پاسخ را محدود کنید
4. مدل quantize قوی‌تر (Q4_K_M معمولاً تعادل خوب است)
