# دیباگ، کامپایلر، Ensemble، بازخورد مدل

**مهدی طریری** — mahditariri@gmail.com

## انتخاب مدل
از لیست `models\*.gguf` در پنل راست → بارگذاری مدل

## دیباگ و کامپایل (Agent)
| ابزار | کار |
|--------|-----|
| `debug_python` | syntax + اجرا + traceback |
| `compile` | py_compile / node --check / gcc / g++ / javac / go / rustc |
| `detect_compilers` | کامپایلرهای نصب‌شده روی سیستم |

کامپایلر باید روی ویندوز نصب باشد (MinGW، JDK، Node، …).

## مدل ترکیبی (Ensemble)
1. حداقل دو فایل `.gguf` در `models\`
2. مدل اصلی را از لیست انتخاب و Load کنید
3. تیک **مدل ترکیبی (Ensemble)**
4. در کادر کمکی: `model2.gguf, model3.gguf`
5. ارسال سؤال

جریان: هر مدل جدا جواب می‌دهد → مدل اصلی یک پاسخ **یکدست** می‌سازد.

> مصرف RAM بالاست چون مدل‌ها پشت‌سرهم لود می‌شوند.

## بازخورد (ترجیح / bandit)
دکمه‌های 👍 / 👎 امتیاز مدل را در `memory/model_feedback.json` ذخیره می‌کنند.
در Ensemble ترتیب مدل‌های کمکی بر اساس این امتیاز مرتب می‌شود.

**یادگیری تقویتی واقعی روی وزن GGUF در این برنامه انجام نمی‌شود**  
(نیاز به GPU سنگین و آموزش LoRA جدا). این بخش یک سیگنال ترجیح برای انتخاب/ترتیب مدل است. برای آموزش واقعی از pipeline دیتاست + LoRA استفاده کنید.

## شبکه عصبی
موتور استنتاج همان شبکه داخل فایل GGUF است (`llama-cpp-python`). آموزش شبکه جدید داخل چت پشتیبانی نشده؛ مسیر LoRA در `scripts/python/` موجود است.
