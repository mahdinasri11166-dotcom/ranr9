# ایده‌های بعدی (اختیاری)

نسخه ۰.۲ تقریباً همه موارد درخواست‌شده را پوشش می‌دهد.

اگر بخواهیم ادامه دهیم:

1. **استخراج متن PDF روی Win7**
   - استفاده از ابزار خارجی سبک مثل `pdftotext.exe` (از xpdf یا poppler قدیمی)
   - یا تبدیل PDF به تصویر و OCR (سنگین)

2. **دانلود مدل از Hugging Face**
   - اسکریپت batch با `curl` یا `bitsadmin` (ابزار قدیمی ویندوز)
   - نمایش پیشرفت

3. **پشتیبانی از چند سرور / چند مدل همزمان**
   - پورت‌های مختلف

4. **ذخیره و بارگذاری تاریخچه چت**
   - فایل JSON ساده

5. **تم روشن / تاریک**

6. **میانبرهای کیبورد بیشتر**

هر کدام را بخواهید، بگویید تا اضافه کنیم.
