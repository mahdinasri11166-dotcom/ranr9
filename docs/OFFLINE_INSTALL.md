# نصب آفلاین (بدون اینترنت بعد از نصب)

**تیم توسعهٔ نو** — مهدی طریری · محسن طریفی

## ایده
GitHub Actions موقع بیلد، **Python توکار + کتابخانه‌های اصلی** (`llama-cpp-python`, `customtkinter`, …) را داخل Installer می‌چسباند.

## کار شما
1. دانلود `GGUF-Runner-Setup-*.exe` از Releases/Actions  
2. نصب  
3. فقط فایل‌های **`.gguf`** را در `models\` بگذارید  
4. `CHAT.bat`

## اینترنت لازم است اگر
- بیلد Actions ناموفق بوده و پوشه `python\` خالی است  
- یا بخش «Optional online update» را موقع نصب تیک زده‌اید  

## مدل‌ها
هرگز داخل EXE نیستند — خودتان اضافه می‌کنید.
