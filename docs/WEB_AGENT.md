# ابزارهای تحت وب (Agent)

**مهدی طریری** — mahditariri@gmail.com

## چه کارهایی پشتیبانی می‌شود

| کار | ابزار |
|-----|--------|
| ساخت سایت استاتیک | `build_website` → پوشه در `workspace\` |
| درخواست HTTP/API | `http_request` |
| جستجو / خواندن صفحه | `web_search` · `web_fetch` |
| باز کردن لینک در مرورگر | `open_url` |
| لیست/خواندن/ارسال ایمیل | `email_*` با فایل secrets |
| کد، zip، دیباگ | ابزارهای قبلی |

## ایمیل
1. کپی `workspace/secrets/email.example.json` → `email.json`
2. برای Gmail از **App Password** استفاده کنید
3. Agent: `email_list` / `email_read` / `email_send`

## آپلود کلیپ / لاگین به هر سایتی
- **لاگین خودکار به حساب‌های دلخواه، دور زدن 2FA/CAPTCHA، و برداشتن پسورد پشتیبانی نمی‌شود** (امنیت و سوءاستفاده).
- آپلود یوتیوب/شبکه‌های اجتماعی نیاز به **API رسمی و OAuth** دارد؛ مدل می‌تواند کد/راهنما بسازد (`save_api_note`) نه اینکه با پسورد شما وارد شود.

## محدودیت
- فقط URLهای عمومی (نه شبکه داخلی)
- نوشتن فایل فقط در `workspace\`
