# دستور فارسی بدون اسلش

نمونه‌ها (Agent روشن باشد؛ مسیر سریع intent هم فعال است):

| جمله شما | ابزار |
|----------|--------|
| سایت example.com را بررسی کن | cyber_quick_audit |
| این موضوع را یاد بگیر: شبکه | learn_topic |
| این لینک را دانلود کن https://... | download_start |
| وضعیت سیستم را بگو | monitor_system |
| ترجمه کن به انگلیسی: ... | translate |
| در اینترنت جستجو کن ... | web_search |
| پورت‌های باز را نشان بده | cyber_net_local |
| زیرنویس این یوتیوب: URL | youtube_transcript |

مدل هم با پرامپت فارسی تشویق می‌شود JSON ابزار بدهد؛ اگر ندهد، router داخلی تلاش می‌کند.
