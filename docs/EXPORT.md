# خروجی کد، ورد، PDF

## مسیر فایل‌ها
`workspace/exports/`

## ابزارها
| ابزار | کار |
|--------|-----|
| make_code_file | ذخیره سورس با پسوند درست (.py .js .java ...) |
| make_document | docx / pdf / md / txt |
| build_and_export | سطح بالا |
| list_exports | لیست فایل‌های ساخته‌شده |

## مثال چت
```
یک برنامه پایتون بنویس که اعداد زوج ۱ تا ۲۰ را چاپ کند و فایلش را بده
یک صفحه HTML ساده بساز
این متن را به صورت فایل ورد بده: ...
خروجی PDF بده از خلاصه گزارش
```

مدل باید کد را تولید کند و `make_code_file` را با `code` پر صدا بزند.
اگر بلد نبود: learn_topic / web_search سپس کدنویسی.
