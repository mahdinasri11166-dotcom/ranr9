# ویزارد اولین اجرا

## اجرا

```bat
FirstRun.bat
```

یا از منوی `GGUF-Runner.bat` گزینه **W**.

```bat
python scripts\python\first_run_wizard.py --force
```

## مراحل

1. **خوش‌آمد** — معرفی کوتاه
2. **بررسی محیط** — Doctor (Python، llama-cpp، پوشه‌ها، مدل‌ها)
3. **مدل‌ها** — پیشنهاد quant، باز کردن `models\`، تازه‌سازی لیست
4. **تست لود** — لود آزمایشی GGUF + یک پاسخ کوتاه (اختیاری)
5. **پایان** — علامت‌گذاری انجام شد و باز کردن چت

## فایل وضعیت

`workspace\.first_run_done.json` بعد از اتمام یا رد کردن ساخته می‌شود.

## نکات

- بدون `customtkinter` ویزارد باز نمی‌شود → `SETUP.bat`
- بدون `.gguf` می‌توانید ادامه دهید ولی چت تا کپی مدل کار کامل ندارد
- تست لود روی مدل خیلی بزرگ ممکن است RAM کم بیاورد؛ ctx تست محدود به ۲۰۴۸ است
