GGUF Runner Portable - no install
Mehdi Tariri | mahditariri@gmail.com

1) Unzip anywhere
2) Run SETUP.bat  (auto-downloads llama-server from GitHub)
3) Put .gguf models in models\
4) Run START.bat

Models are NOT auto-downloaded.
Optional Python packages install if Python is on PATH.

See docs\AUTO_SETUP.md
